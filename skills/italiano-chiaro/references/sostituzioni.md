# Sostituzioni: dalla parola abusata alla parola comune

Questa tabella è di questa skill, non di uno standard. Se la parola non porta un fatto, cancellala e non sostituirla.

## Slop da LLM

| Parola | Scrivi invece |
|---|---|
| cruciale, fondamentale, essenziale | importante, o cancella e scrivi il fatto |
| robusto, esaustivo | Cancella, o scrivi la proprietà misurabile |
| innovativo, all'avanguardia, rivoluzionario | nuovo, o cancella |
| sinergia, panorama, arazzo, ecosistema (metaforico) | Cancella, o nomina le parti |
| approfondire, immergersi in, addentrarsi in | leggere, studiare |
| potenziare, valorizzare | migliorare, o scrivi che cosa cambia |
| senza soluzione di continuità, senza sforzo, in modo semplice | Cancella |
| semplicemente, facilmente, basta | Cancella |
| un vero e proprio, a 360 gradi, a tutto tondo | Cancella |
| vale la pena notare che, è importante sottolineare che | Cancella, poi scrivi il fatto |
| in conclusione, in sintesi, in definitiva | Cancella |
| è progettato per, mira a, ha l'obiettivo di | Cancella, poi scrivi che cosa fa |
| ti permette di, ti consente di | puoi |
| per quanto riguarda, in termini di | per |
| gestisce in modo elegante | Scrivi che cosa fa: "riprova tre volte, poi si ferma" |
| sotto il cofano, dietro le quinte | internamente |
| una miriade di, una pletora di | molti |
| funzionalità | funzione |
| Spero di esserti stato utile, Fammi sapere, Resto a disposizione | Cancella |

Queste parole sono normali nei testi tecnici ("percorso completo", "esplora la cartella"). Il linter le segnala solo come avviso. Cancellale quando non portano un fatto:

| Parola | Quando cancellarla |
|---|---|
| potente | Quando non segue un numero o una capacità precisa |
| completo | Quando è un vanto ("una soluzione completa") |
| esplorare | Quando è una metafora ("esploriamo il tema") |
| sfruttare | Quando "usare" dice lo stesso |
| ottimizzare | Quando non dici che cosa migliora e di quanto |

## Burocratese

| Parola | Scrivi invece |
|---|---|
| al fine di, allo scopo di | per |
| nell'ambito di | in |
| a seguito di | dopo |
| in data odierna | oggi |
| in fase di, in sede di | durante |
| provvedere a, procedere a | Il verbo dell'azione: "procedere all'invio" → "invia" |
| effettuare | fare, o il verbo dell'azione |
| espletare | svolgere |
| porre in essere | fare |
| inoltrare | inviare |
| pervenire | arrivare |
| utilizzare | usare |
| qualora, laddove | se |
| ove | se, dove |
| risulta essere | è |
| suddetto, predetto, sopracitato | Ripeti il nome |
| e/o | "o", oppure "X, Y o entrambi" |
| si prega di | L'imperativo |
| entro e non oltre | entro |

## Anglicismi evitabili

| Parola | Scrivi invece |
|---|---|
| settare | impostare |
| settaggio | impostazione (un valore), configurazione (l'insieme) |
| schedulare | pianificare |
| fixare | correggere |
| droppare | eliminare |
| runnare | eseguire |
| killare | fermare |
| checkare | verificare |

I termini tecnici veri restano: deploy, commit, merge, endpoint, build, log. Usa sempre lo stesso nome per la stessa cosa.

## Abbreviazioni

| Abbreviazione | Scrivi invece |
|---|---|
| es., p.es., e.g. | per esempio |
| i.e. | cioè |
| ecc., etc. | Nomina gli elementi |
| cfr. | vedi |
| c.d. | Cancella, o scrivi "chiamato" |
